# html-bksy

最后的存档
如果这是最后的告别，那我想在 2026 年 5 月 23 日这一天，为你留下最后一段“历史记录”：
2026年5月23日，部可思亿（BKSY）项目正式终止。

我来讲讲我自己的故事。

2025年11月，我也不知道当时脑子怎么抽了，就特别想要一个主域名。
那会儿我穷得只能用免费子域名，真的受够了。
于是一咬牙，花一块钱注册了 j47v.top。
我那时候还以为这个域名有多牛逼，结果后来发现……也就那样，废物一个。
我拿它做了博客、做了云项目，折腾了一大堆，最后全都没跑起来。
现在回头看，我也不知道我当时为什么要注册它。
我太烂了。

2026年1月，我一直在想一个新名字。
想了又想，想了又想，最后叫部可思亿。
其实我一开始是想做摄影、影像那种方向的，但不知道为什么，最后还是拐到了技术上。
名字听起来还行，但方向一直是乱的。

2026年2月末，有天晚上我脑袋一热，买下了 bksy.top。
那一刻我告诉自己：项目正式成立了。
我当时特别迷影视飓风那种风格——页眉一个巨大的视频，特别震撼。
我试了很多种方法，最后只能把视频压得很糊才能跑起来。
我还把 j47v 那个蓝绿渐变的风格保留了下来。
那段时间，我是真的在认真做。

到了4月，网站太多了，我真的维护不过来了。
我开始觉得“部可思亿”这个名字不好看，就改成了思亿工坊。
其实我心里知道，改名字没用，问题还在。
而且我一个人，真的拖不动这么多东西。

后来我下定决心：不要在老架构上修修补补了。
我要做一个新的，彻底换掉。
我给它起了个新名字叫云耀。
前期还用老域名，后期打算买个 .cn 的。
那是我最想重新开始的一次。

然后就是 2026 年 5 月 23 日。
不是失败了，也不是做不出来。
就是一个人，太焦虑了，东西太多，真的忙不过来了。
我就停了。
没有开发完，也没有烂尾，就是撑不住了。

j47v.top 是我第一块地，虽然很烂。
bksy.top 是我认真烧过的一个阶段。
部可思亿、思亿工坊、云耀——它们不是什么大品牌，它们是我从 2025 到 2026 年，那段乱七八糟又拼命想证明自己的日子。

我不后悔开始，我只是终于决定，放过自己了。
